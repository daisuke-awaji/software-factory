# ADR-0010: 依頼の一覧を、折りたためる左のサイドパネルに移す

- 状態: Proposed
- 日付: 2026-11-07
- 関連: 要件 FR-UI-01・02・08 / [UI 仕様](../06_ui_spec.md) §1・§6 / [ADR-0007](./0007-workspace-layout.md)（一覧の置き場所を置き換える）

## 背景
ADR-0007 では、依頼の一覧をホームの表にし、ワークスペースからはヘッダーのドロップダウンでほかの依頼に切り替える形にした。左に折りたためるサイドバーを足す案は、「会話と成果物の2列に3列目が加わり、1280px 前後で窮屈になる」として採らなかった。

この形には、次の問題がある。

1. 承認待ちや実行中の依頼を気にしながら別の依頼を進めるとき、そのたびにホームへ戻る必要がある
2. ドロップダウンには最近の8件しか出せず、状態も一覧として見られない
3. スマホでは、上部のナビゲーション（右上のメニュー）と、ワークスペースの「戻る」ボタンの2つの入り口がある

## 決定
- **左にサイドパネルを置き、全画面で共通にする。** 中身は、新しい依頼、画面の移動（すべての依頼・公開物・イメージ・ライン・管理）、依頼の一覧（検索と「対応が必要 → 実行中 → 最近」）、アカウント。上部のナビゲーションはなくす
- **ADR-0007 で心配した 1280px 前後の窮屈さは、幅で出し方を変えて避ける。**
  - 1280px 以上: 広げて横に置く（264px）。畳むとアイコンの列（56px）になり、畳んだかどうかを覚えておく
  - 1280px 未満: いつもアイコンの列にし、広げるときはページに重ねる（ページの幅は変えない）
  - 720px 未満: 列も出さず、上の細いバー（ワークスペースではヘッダー）の左のボタンで、左から重ねて出す
- **ワークスペースのヘッダーは、画面の幅ではなくワークスペースの幅（コンテナー クエリー）で出し分ける。** サイドパネルを開け閉めしても、タイトルが潰れないようにする
- ホームは「新しい依頼・対応が必要な項目・この7日間」にする。状態・ライン・所要・費用を見比べる表は「すべての依頼」（`/requests`）に移す
- ワークスペースのヘッダーの「ほかの依頼に切り替える」ドロップダウンはなくす（サイドパネルで切り替える）

## 検討した選択肢
| 案 | 良い点 | 悪い点 |
|---|---|---|
| **サイドパネル + 幅で出し方を変える（採用）** | どの画面からでも依頼を切り替えられる。承認待ちが常に見える | 1280px 未満では一覧を見るのに1回押す必要がある |
| サイドパネルをいつも横に置く | 一覧がいつも見える | 1024〜1279px で会話と成果物が窮屈になる（ADR-0007 の懸念のまま） |
| ホームの表のままにし、ドロップダウンを強くする | 画面の作りを変えなくてよい | 一覧として眺められない。ホームへの行き来が残る |

## 結果
- 良くなること: 依頼の切り替えが1回で済む。承認待ちの件数がどの画面でも見える。スマホでも入り口が1つになる
- 悪くなること: 表で見比べるには「すべての依頼」へ移る必要がある。サイドパネルの一覧の読み込み（20秒ごととイベント）が、ホームやすべての依頼の読み込みと重なる
